# x402 paid FX quote (2026-11-05), branch `x402-quote`

## Fait

- `GET /api/x402/fx-quote?currency=ARS|BRL&amount=<decimal, max 2 dp>`: paid 0.001 USD₮ or USDC over x402 v2, through
  Celo's facilitator (`api.x402.celo.org`). Returns the amount of USD₮ and of USDC needed to deliver exactly that wFIAT
  amount via Uniswap V3 (solver, single leg, no Textile), with `costBps` against the reference rate.
  Code: `apps/web/lib/server/x402.ts`, route `apps/web/app/api/x402/fx-quote/route.ts`, wiring `getFxQuoteDeps()` in
  `apps/web/lib/server/deps.ts`.
- Order: free parameter check (400) → x402 verify (402 if missing/invalid) → quote → settle only on success
  (502 `no_route` / `upstream_unavailable` leave the caller uncharged). IP rate limit (bucket `quote`).
- Off unless `X402_API_KEY` and `X402_PAY_TO` are set (503 `not_configured`). Added to `.env.example`.
- Tests: `apps/web/test/x402.test.ts` (7), with a fake facilitator and a real x402 client signing EIP-3009 with an anvil
  test key: 402 shape, paid path, no settlement on failure, rejected payment.
- Read-only smoke against mainnet (no payment): the live facilitator's `/supported` initialises the server and the 402
  is produced; real quotes: 4 500 ARS ≈ 2.723 USD₮ (−3.6 bps), 50 BRL ≈ 9.447 USD₮ (325 bps, pool).

New dependencies (exact): `@x402/core@2.29.0` (resource server, HTTP facilitator client, header codec) and
`@x402/evm@2.29.0` (`exact` EVM scheme). Both are the reference x402 v2 packages that Celo's docs use; hand-rolling the
v2 header format would be riskier. 2.29.0 rather than 2.30.0: 2.30.0 was published on 2026-11-04 and fails pnpm's
`minimumReleaseAge` supply-chain policy; no policy exception was added.

## À relire

- Not merged, not pushed. The agent card keeps `x402Support: false` until the endpoint is live with a key.
- Facilitator settlements are sent by its signer and carry no ERC-8021 tag (checked on 8 recent settlements): they
  are not attributed to Cobrá by tag. This only adds "uses Celo's x402 facilitator".
- Indicative quotes only: wBRL shows the pool price, not the Textile RFQ price real payments get.

## Bloqué (human)

- Create the API key on x402.celo.org (wallet signature, no tx), set `X402_API_KEY` and `X402_PAY_TO` in Vercel.
- One real paid call from an x402 client (e.g. `buy`) to confirm settlement end to end, then set `x402Support: true`
  and list the endpoint in the agent card.
