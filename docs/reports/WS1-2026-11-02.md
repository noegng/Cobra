# WS1 (router contract): night report, 2026-11-02

Branch `ws1-router`, scope `contracts/**`. Main (f5a7aee) is merged in.

## Fait

- `src/CobraRouter.sol` implements `ICobraRouter` as described in §2–§3. It has two immutables (`PERMIT2`, `SWAP_ROUTER` = SwapRouter02), a transient reentrancy lock (TSTORE checked on Celo mainnet with eth_call), and `isPaid` keyed by the struct hash and set before any external call.
  - Pull kinds: EIP-3009 (with the router-recomputed `legNonce`), Permit2 witness, and ALLOWANCE (`msg.sender == payer`).
  - Accounting uses balance deltas, approvals are exact and then reset, and there is one aggregate `InsufficientOutput` check. Any surplus goes back to the payer.
- Hand-written minimal interfaces and a tiny `SafeTransfer`; no new dependencies.
- Tests: **73 green**.
  - Vectors: 4.
  - AbiParity: 1.
  - Unit: 58, covering tampering of every field, paths, replay, front-running, fee-on-transfer, no-return tokens, pause/blocklist, reentrancy and fuzzing.
  - Invariants: 4, with 16,384 calls.
  - **Fork: 9 run, 0 skipped**, against the real Permit2, SwapRouter02 and QuoterV2 with USDC/USDT EIP-3009 and wARS/wBRL. They are skipped when the RPC is down.
- The shared abi-parity test is green.
- `script/Deploy.s.sol` was dry-run only (2.45M gas). The human command is in `contracts/SECURITY.md`.

## À relire

Deviations from the spec, all stricter:
- The merchant's balance delta must equal `amountOut`.
- The unswapped residue from a partial fill is refunded.
- Paths are capped at 4 hops.
- The constructor rejects zero addresses.
- `fs_permissions` now includes `./out`.

Open questions are in `contracts/SECURITY.md`. The main one: **the anvil #0 and #1 addresses carry EIP-7702 delegations on Celo**. For 7702-delegated payers, USDC, USDT and Permit2 verify signatures through ERC-1271, so WS5 must handle that case.
